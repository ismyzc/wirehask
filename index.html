Quick start

Install & activate

  1. Get a license — complete checkout and your license key is issued to your email.
  2. Download the installer for your platform from the latest release.
  3. Activate from the app (Help → Activate License) or from the command line below.

Command-line capture

# capture HTTPS traffic on eth0 into a 100 MB ring buffer netrova-cli capture -i eth0 -f "tcp port 443" --ring 10x10MB -w session.pcapng # read a capture and show only TLS Client Hello packets netrova-cli read session.pcapng -Y "tls.handshake.type == 1" # top conversations by bytes netrova-cli stats conv session.pcapng --sort bytes --top 20
